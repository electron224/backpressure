## sim-core data flow
Topology → compile() → SimGraph → run() → {eventLog, metrics, verdicts}

- Topology: {nodes: {id, kind, config}[], edges: {from, to}[]}
- compile(): validate ids unique, kinds known, single client source, edges reference ids, cycle-check (DFS), build adjacency. Throw with context on failure.
- Rng: xorshift128+ seeded from seed. next(), nextInt(n), zipf(alpha) for keys. No Math.random/Date.now/performance.now anywhere.
- SimClock: virtual nowMs, binary-heap priority queue {at, seq, kind, target, payload}. Tie-break by seq for determinism.
- TrafficProfile: {rps, readRatio, keyAlpha, payloadBytes}. Client schedules arrivals via exponential inter-arrival (via Rng).
- Scenario (M0 subset): [{at, fault: 'kill-node'|'traffic-spike', targets?}]. Full fault list deferred to M1.
- Metrics: 1s buckets — p50/p99 (sorted latency array per bucket), throughput, per-node queueDepth, errors. Derived metrics carry trace: string.
- Verdicts (M0): slo.p99 {observed, threshold, explanation}, throughput.sustained.

## Components
Interface (plain TS for M0; Zod in M1):
init(config, ctx) → state; onRequest(req, state, ctx) → Response|Defer; onTick?; onFault?; metrics(); narrate(): string.

- client: source/sink. Generates per TrafficProfile, records e2e latency on completion.
- load-balancer {strategy: round-robin|least-connections|weighted|consistent-hash, weights?}: tracks inflight per backend. RR intentionally naive.
- service {serviceMs, concurrency, queueLimit}: if inflight<concurrency complete after serviceMs else FIFO queue; overflow → 503. Exposes queueDepth.

Demo topology: client → lb → [fast service 20ms, slow service 80ms]. At 100 RPS RR p99 blows past 150ms SLO, least-conn holds. This divergence is the lab's "fun".

## Lab preset
content/concepts/load-balancing/lab.ts exports {topology, controls: [strategy, rps, fastSlots, slowSlots], metrics: [p99, throughput, queueDepth], challenges: [p99<150ms via strategy, survive 1 backend kill]}.
demo/ runs RR vs least-conn side-by-side, prints tables + narrate() lines.

## Testing
- determinism: same seed ×2 → identical eventLog hash (vitest).
- units: Rng vector, heap ordering + seq tiebreak, RR uniform distribution, queue overflow → 503, kill-node flips verdict.
- worker-safe: grep lint for Math.random/Date.now/window/document in sim-core (CI later).
- a11y placeholder: tabular metrics output (no color-only, no mouse-only).

## Risks
- p99 noise at low event counts → fixed 1s buckets + min-sample guard.
- Heap bug breaks determinism → seq tiebreak + unit test.
- Scope creep into Next.js → deferred explicitly to M1.
