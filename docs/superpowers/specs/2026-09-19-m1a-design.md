# M1a Concept Loop — Design

Date: 2026-09-19
Status: approved
Scope: M1 first slice. Four-stage loop infra + predict-then-reveal + chaos button + localStorage, proven on load-balancing. Remaining 9 concepts are content-only follow-ups.

## Goal
A learner opens `/concepts/load-balancing`, reads ≤600 words, plays with strategy/RPS sliders on the real M0 engine in-browser, commits a p99 prediction, hits chaos, attempts machine-graded challenges, and does recall — progress persisted in localStorage. Shippable to 20 people with no auth/DB.

## Non-goals (M1a)
Web Worker (runs sub-ms; M2), auth/DB/FSRS (M4 per build order), Turborepo (single app), Playwright e2e (M1b), `content:lint` script (M1b), remaining Tier 1+2 concepts (follow-ups), any `sim-core`/`sim-components` behavior change.

## Layout (additive; M0 untouched)
```
apps/web/ — Next.js App Router, TS strict, Tailwind
  app/concepts/[slug]/page.tsx — Server: load + Zod-validate content, render Learn, pass preset to island
  components/concept-lab.tsx — 'use client' island: Play/Stress/Predict/Chaos (~200 lines)
  components/metric-table.tsx — 'use client': tabular metrics, text PASS/FAIL
  lib/content.ts — Server-only content loader (read + validate)
packages/concept-engine/ — pure TS; deps: sim-core, sim-components, zod only
  src/schema.ts — Zod schemas: ConceptMeta, Challenges, RecallItems
  src/predict.ts — prediction error helpers (pure): error = |predicted - actual|
  src/chaos.ts — pickRandomFault(rng, targets): ScenarioEvent (seeded, deterministic)
  src/progress.ts — localStorage adapter: stage completion + predictions log (Storage-injected, testable in Node)
content/concepts/load-balancing/ += meta.json, learn.mdx, challenges.json, recall.json
```

## Content model (per AGENTS.md §6, enforced by Zod)
- `meta.json`: {id, title, prerequisites[], difficulty, estimated_minutes, tags[]}
- `learn.mdx`: ≤600 words (enforced by unit test word count, not prose review)
- `lab.ts`: existing preset (controls, metrics, challenges lb.1/lb.2) — unchanged
- `challenges.json`: [{id, text, verdict}] mirroring lab.ts challenges, machine-verified by Verdicts
- `recall.json`: [{id, q, a}] static items; self-marked; FSRS deferred to M4

## Data flow
Content dir → schema.ts validation at page load (dev: throw with file+field; prod: 404 + log context) → Server renders Learn → client island:
Play (sliders → run() in-browser, seed 7 default) → Predict (p99 slider, commit locks, run reveals actual+error → progress.logPrediction) → Chaos (button → pickRandomFault → scenario re-run, verdict flip) → Stress (challenge buttons → verdicts PASS/FAIL) → Recall (Q/A reveal, self-mark → progress.completeStage).
No LLM anywhere. Pass/fail from Verdicts only.

## Lab island states
`idle → predicted → revealed` (predict lock); chaos is a one-shot re-run with scenario appended, announced as text. Controls: strategy select, RPS slider (10–300), p99 predict slider, chaos button, challenge buttons. Side-by-side RR-vs-LC table + narrate() lines. All keyboard-operable; table alongside any visual; text PASS/FAIL (AGENTS.md §9).

## Predict + chaos + progress (exact semantics)
- `predict.ts`: `predictionError(predictedMs, actualMs): number` = abs diff; `gradePrediction(errorMs, toleranceMs): boolean` = error <= tolerance (default tolerance 50ms).
- `chaos.ts`: `pickRandomFault(rng, backends): ScenarioEvent` — deterministic: `kill-node` on random backend (60%) or `traffic-spike` 2x for 5s (40%). Seeded from Date-free counter + stored seed so refresh reproduces.
- `progress.ts`: `createProgress(store: Storage)` → {completeStage(slug, stage), logPrediction(slug, {predicted, actual, error}), get(slug)}. Keys `bp:<slug>` JSON. No cross-tab sync (M4).

## Testing
- concept-engine units (Vitest, Node, no browser): schema accepts-good/rejects-bad; predict math + tolerance boundary; chaos determinism (same seed → same fault) + distribution sanity; progress with in-memory Storage stub (round-trip, corrupt-JSON recovery → reset, never throw).
- learn.mdx word-count test (≤600).
- M0 determinism suite still green (untouched).
- Manual ship-to-20 for loop-fun; Playwright deferred to M1b.

## Risks
- Client bundle pulls sim code — fine at this size; Worker at M2.
- localStorage corrupt JSON → adapter resets that key, logs warning, never crashes page.
- SSR/CSR agreement — fixed default seed 7; no server-run vs client-run split.
